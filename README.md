# Olist E-Commerce Data Analytics Project

## Project Overview
This project analyzes the Brazilian E-Commerce Public Dataset by Olist to understand sales performance, product categories, customer purchasing behavior, and customer reviews.

The project uses MySQL for data analysis, Python for data processing and visualization, and Power BI to build an interactive business dashboard.

## Tools & Technologies
- **MySQL:** Data querying and analysis
- **Python:** Pandas and Matplotlib
- **Power BI:** Dashboard and data visualization
- **Excel/CSV:** Data export and handling

## Business Questions
- How do monthly orders and revenue change over time?
- Which product categories generate the highest sales?
- What is the proportion of repeat and one-time customers?
- How are customer review scores distributed?
- What insights can help improve the e-commerce customer experience?

## Project Workflow
1. Imported and analyzed Olist dataset tables using MySQL.
2. Exported analysis results into CSV files.
3. Used Python and Pandas to validate data and analyze trends.
4. Created visualizations for sales, categories, customers, and reviews.
5. Built a Power BI dashboard to present key findings.

## Key Analysis Areas
- Monthly order trends
- Monthly payment-value trends
- Top 10 product categories by product sales
- Repeat versus one-time customers
- Customer review score distribution

## Key Business Takeaways
The analysis explores opportunities to improve customer retention, identify high-performing product categories, monitor sales trends, and investigate customer experience issues.

Actual findings should be interpreted using the results generated from the dataset. Revenue and product sales are separate measures in this project.

## Repository Contents
